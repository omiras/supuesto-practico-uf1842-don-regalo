# Supuesto práctico · Don Regalo

**UF1842 · Primera evaluación continua · Duración: 2 horas**

Don Regalo prepara su campaña de compras navideñas. Resuelve los cinco ejercicios con JavaScript. Cada ejercicio es independiente: puedes continuar con el siguiente aunque uno no te salga.

1. Abre `index.html` en el navegador y entra en el primer ejercicio.
2. Lee «Antes de empezar» y «Tu turno». Edita únicamente el bloque `<script>` señalado como **CÓDIGO DEL ALUMNADO** en el HTML del ejercicio.
3. Guarda el archivo y recarga la página. Al final verás «Comprueba tu solución». En los ejercicios 1, 2 y 3 se revisa la salida de consola con los datos iniciales; en los ejercicios 4 y 5 se prueban varios casos. También puedes abrir **F12 → Consola**.
4. Entrega la carpeta con los cinco archivos HTML modificados. Conserva `style.css`, `captura.js` y `pruebas.js` para que funcionen las comprobaciones.

| Ejercicio | Tema | Puntos |
| --- | --- | ---: |
| [1 · Importe de la compra](index1.html) | Variables y operaciones | 1,5 |
| [2 · Envoltorio gratuito](index2.html) | `if...else` y `&&` | 1,5 |
| [3 · Preparación de pedidos](index3.html) | Bucle | 1,5 |
| [4 · Códigos de descuento](index4.html) | Función con parámetros y `return` | 2,5 |
| [5 · Resumen de ventas](index5.html) | Recorrido de arrays | 3 |

Las pruebas ayudan a revisar tu trabajo. La corrección también tendrá en cuenta el código y si cumple lo solicitado en el enunciado.
