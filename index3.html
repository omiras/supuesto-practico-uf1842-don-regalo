Ejercicio 3 · Precios con IVA

Bucles y arrays · 1,5 puntos

Antes de empezar

Don Regalo guarda en un array los precios de varios artículos antes de aplicar el IVA. Quiere mostrar al personal de la tienda cuánto cuesta cada artículo después de añadir un 21 % de IVA.

Tu turno

Recorre el array precios con un bucle. Para cada posición, calcula el precio con IVA y muestra una línea con el formato El artículo N cuesta PRECIO tras aplicar un 21% de IVA. Los artículos se numeran desde el 1, aunque las posiciones del array comienzan en 0. Todos los precios finales deben mostrarse con exactamente dos decimales.

  • No intentes conseguir todo a la vez.
  • Primero, muestra cada precio original por consola.
  • Luego, muestra cada precio después de aplicar el 21 % de IVA.
  • Después, construye el mensaje completo con el número del artículo.
  • Finalmente, muestra cada precio final con dos decimales.

Haz los cálculos a partir de los valores del array; no escribas directamente los resultados esperados. Edita el último bloque <script>, guarda y recarga la página.

Resultado esperado en consola

Con los precios iniciales, deben aparecer estas cuatro líneas, en este orden:

El artículo 1 cuesta 121.00 tras aplicar un 21% de IVA
El artículo 2 cuesta 24.19 tras aplicar un 21% de IVA
El artículo 3 cuesta 60.50 tras aplicar un 21% de IVA
El artículo 4 cuesta 181.50 tras aplicar un 21% de IVA

Comprueba tu solución

La página compara las cuatro líneas mostradas en la consola con las esperadas para los precios iniciales. La corrección también revisará que recorras el array, calcules el IVA y muestres dos decimales.
