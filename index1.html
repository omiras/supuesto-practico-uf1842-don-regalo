Ejercicio 1 · Importe de la compra

Variables y operaciones · 1,5 puntos

Antes de empezar

Un peluche tiene un precio de 12,125 € y un juego de mesa cuesta 18 €. Una clienta compra 3 peluches y 2 juegos.

Tu turno

En el código tienes las cantidades y una variable para cada precio. Usa esas cuatro variables para calcular el importe total, redondéalo a dos decimales y muéstralo con console.log. Se acepta el resultado tanto como número como en el texto que devuelve toFixed(2); no hace falta convertirlo.

Edita el último bloque <script>, guarda y recarga la página.

Importante para la evaluación

Debes ceñirte a lo que pide cada ejercicio y realizar los cálculos o las comprobaciones con JavaScript. Que la prueba muestre un resultado correcto no basta si el código no resuelve el problema.

Por ejemplo, en el ejercicio 1 no es suficiente escribir console.log(72.38): tienes que calcular el importe utilizando las variables de cantidades y precios y redondear el total.

Resultado esperado en consola

Con los datos iniciales, debe aparecer este importe redondeado:

72.38

Comprueba tu solución

La página compara el número mostrado en la consola con el importe esperado para los datos iniciales.
